# HiQuant logo assets

These are the original 1254 x 1254 PNG logo variants supplied by the business owner.

## Initial usage recommendation

- `logo_white_bg.png`: primary logo for white and light page surfaces
- `log_color2_bg.png`: preferred full-brand treatment for navy surfaces
- `logo_black_bg.png`: alternate treatment for black or near-black surfaces
- `logo_color1.png`: alternate teal-background treatment
- `logo_5.png` through `logo_9.png`: retained source variants pending the Phase 1 brand review

The original files are preserved without modification. They are square RGB images and do not contain an alpha channel. During Phase 1, create web-optimized derivatives for the navigation header, footer, favicon, and social preview while retaining these originals.
