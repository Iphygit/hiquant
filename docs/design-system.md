# HiQuant web design system

## Direction

The website uses a restrained, professional consulting aesthetic. It should feel credible in scientific and regulated environments without resembling a clinical portal, and modern in technology contexts without relying on generic futuristic imagery.

## Core palette

| Token | Value | Primary use |
|---|---|---|
| Navy 950 | `#03142f` | Hero and footer backgrounds |
| Navy 900 | `#071f45` | Headings and primary text |
| Navy 800 | `#0b2e5f` | Elevated dark surfaces |
| Teal 700 | `#078b88` | Accessible accent text and section backgrounds |
| Teal 500 | `#12b7b1` | Brand accents and primary actions |
| Teal 100 | `#dff7f5` | Soft accent backgrounds |
| Ink | `#162033` | Body text |
| Slate | `#546174` | Secondary text |
| Mist | `#f4f7fa` | Alternating section background |
| Line | `#d9e1e8` | Borders and dividers |

## Typography

The initial system uses a native sans-serif stack for speed, privacy, and reliability. Headings use tight tracking and strong scale contrast. Body copy maintains a generous line height for readability.

## Layout

- Maximum content width: 74rem
- Fluid side margins with a 1rem minimum on standard screens
- Large section spacing to support a calm, premium feel
- Two-column layouts collapse below 56rem
- Primary mobile adjustments occur below 40rem

## Components

- Sticky site header with accessible mobile navigation
- Primary, small, and light button variants
- Eyebrow labels for section context
- Service cards with restrained hover feedback
- Structured lists for industries and process steps
- Dark footer with legal-information region

## Accessibility baseline

- Semantic landmarks and heading hierarchy
- Skip link
- Visible keyboard focus
- Touch-friendly controls
- Escape-to-close mobile navigation
- Motion reduction support
- Decorative logo instances use empty alternative text because the adjacent brand name supplies the accessible name
